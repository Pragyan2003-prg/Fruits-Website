# Fruits Website 

A responsive fruits and organic food website built using HTML, CSS, Bootstrap, and JavaScript.

## About the Project

Fruits Website is a responsive website designed for an organic food and fruits business.
It provides a clean and user-friendly interface to explore products, view the gallery, learn about the website, and get in touch.

## Features

- Responsive design
- Home page
- About section
- Product section
- Gallery section
- Contact form
- Responsive navigation bar
- Bootstrap-based layout
- Interactive UI

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
